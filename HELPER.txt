Project Overview & ArchitectureProject Dormant is a privacy-preserving contactless monitoring system that uses Wi-Fi Channel State Information (CSI) between two ESP32 nodes to detect subtle environmental and physiological fluctuations (like breathing and movement) without requiring wearables or cameras.Hardware & Software Setup:Hardware: Two ESP32-WROOM-32U microcontroller boards (1 Transmitter, 1 Receiver) connected via USB COM ports.Firmware Framework: ESP-IDF v5.5.5 (C/C++).Data Logger: Python script (csi_logger.py) running on an edge PC using pyserial and pandas.2. 3. The Technical Journey: Challenges Faced & How We Solved ThemAgle developer ko yeh samajhna bohot zaroori hai ki humne shuruat me kya ghaltiyan avoid ki hain aur final solution tak kaise पहुंचे:Challenge 1: AP-STA Connection Drops (reason = 209)Problem: Initially, we tried connecting the ESP32 boards via standard Wi-Fi Access Point (AP) to Station (STA) mode without a physical router. The ESP32's power management and beacon timeouts kept dropping the connection with reason 209, causing 30-minute logging sessions to drop down to a mere 15 packets.Solution: We abandoned traditional connection handshakes. Instead, we shifted to a Raw Wi-Fi Packet Injection & Promiscuous Sniffing Architecture. The Transmitter continuously injects raw 802.11 broadcast frames on Channel 1, and the Receiver acts as a passive sniffer capturing CSI data without any association overhead. This achieved a rock-solid, gap-free ~12.5 Hz continuous data stream.Challenge 2: ESP-IDF v5.5 Strict Packet FilteringProblem: Newer ESP-IDF versions block unrecognized QoS or data frame injection by default, throwing unsupport QoS frame type errors.Solution: Configured custom management/broadcast frames and enabled WIFI_PROMIS_FILTER_MASK_DATA | WIFI_PROMIS_FILTER_MASK_MGMT masks on the receiver.4. Step-by-Step Instructions for the Next PersonAgle person ko dataset banane ke liye bas yeh steps follow karne hain:Step 1: Flash the FirmwareOpen terminal in Dormant_TX/ and flash the transmitter:Bashidf.py build
idf.py -p COM_TX flash
(Replace COM_TX with the correct COM port for the TX board)Open terminal in Dormant_RX/ and flash the receiver:Bashidf.py build
idf.py -p COM_RX flash
(Replace COM_RX with the correct COM port, e.g., COM10)Step 2: Run the Python Data LoggerMake sure no ESP-IDF monitor is locking the COM port, then run the logger script from the workspace directory:Bashpython csi_logger.py
What it does: It opens the serial port, filters incoming lines starting with CSI_DATA, extracts the RSSI value and the 128 raw subcarrier values (64 subcarriers $\times$ I/Q components), and logs them into a timestamped .csv file.Target Output: You will see continuous logs like Saved: 50 packets | Rate: 12.5 pkts/sec.5. CSV Data Format ReferenceEach row generated in the CSV file represents a single Wi-Fi packet snapshot containing:Timestamp: High-precision timestamp (YYYY-MM-DD HH:MM:SS.fff)RSSI: Received Signal Strength Indicator (dBm)Subcarrier_1 to Subcarrier_128: Raw integer amplitude/phase components representing the multi-path radio environment.Aap yeh document aur upar wala folder seedha agle developer ko de sakte hain.
